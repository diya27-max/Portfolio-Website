# Diya Chakravarti | Web Developer Portfolio 🚀

A premium, modern personal portfolio website designed with a dark maroon aesthetic, featuring advanced CSS animations and interactive glassmorphism.

## 🔗 Live Demo
Check out the live site here: [https://diya27-max.github.io/Portfolio-Website/](https://diya27-max.github.io/Portfolio-Website/)

## ✨ Key Features
- **3D Floating Skill Cards**: Interactive expertise showcase with perspective tilt and floating animations.
- **Glassmorphism UI**: High-end translucent design with background blurs and sleek gradients.
- **Responsive Layout**: Fully optimized for mobile, tablet, and desktop viewing.
- **Printable CV**: Dedicated print-optimized CV page for professional use.
- **Interactive Navigation**: Smooth scrolling with a dynamic glass navbar.

## 🛠️ Tech Stack
- **Languages**: Java, HTML5, CSS3, JavaScript (ES6+)
- **Design Tools**: Figma, Adobe XD
- **Icons**: Font Awesome, Devicons

## 🎨 Design Theme
- **Primary Color**: #ff1f40 (Vibrant Maroon/Red)
- **Background**: Dark Mode with Glassmorphic overlays
- **Typography**: Poppins, Inter, and Orbitron

## 🚀 Deployment
Deployed using **GitHub Pages**.
